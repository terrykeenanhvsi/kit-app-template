# Solitaire App Template

A small, UI-first application template that scaffolds a Solitaire (card game) application built with Omniverse Kit. Use this template to generate a complete app and a small extension when you run `repo.sh template new` / `repo.bat template new`.

This template is intentionally lightweight — it focuses on 2D UI and game logic separated into an optional extension so you can iterate quickly.

Key ideas and structure
- Application (.kit) — sets up a UI app and minimal windows. Good for packaging and launch configuration.
- Recommended extension — put the game rules, card assets and UI widgets inside an extension (e.g. `my_company.solitaire_logic`) so it can be reused or tested independently.

Files generated by the template
- `source/apps/<your_app>.kit` — the generated kit app (based on `solitaire.kit`).
- `source/extensions/<your_extension>/` — (recommended) a starter Python extension for game logic, UI widgets and sample assets.

Usage

Create a new application from this template (Windows PowerShell):

```powershell
.\repo.bat template new
```

Select:
- Application
- Solitaire
- Provide application name, display name and version when prompted

After creating your application, follow the normal build/launch cycle:

```powershell
.\repo.bat build
.\repo.bat launch
```

Design notes for contributors
- Keep UI and Game logic separate: place core rules and model code in an extension under `source/extensions/<your_ext_name>/`.
- Use `omni.kit.uiapp` and lightweight windows (toolbar, file menu) for UI; renderers and heavy scene delegates are unnecessary for a 2D card game.
- Store card art or JSON-based card definitions under `assets/` inside your extension or under an app `content/` folder so tests and packaging can include them.

Testing & Iteration
- Add unit tests for game rules under `tests/` inside the extension.
- Use the `repo.bat test` target to run tests after a build.

Example extension name suggestions
- `my_company.solitaire_logic` — game rules, win/loss detection, score
- `my_company.solitaire_ui` — UI panels, visual card widgets, keyboard/mouse handlers
